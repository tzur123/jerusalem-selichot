Add a Waze-style route preview screen between /start and live navigation

- New /route/[stationSlug] page + RoutePreview component: zoomed-out map
  showing the visitor's location and all 5 station pins at once, with a
  bottom card summarizing real walking distance/time to the chosen start
  station before committing to turn-by-turn navigation
- Tapping any other pin opens an info popup with a "choose as start point"
  action, switching the previewed route (and the session's start station)
  without leaving the screen
- "start navigation" button on the preview card hands off to the existing
  /navigate/[stationSlug] screen
- StartFlow now routes through /route/[slug] instead of jumping straight
  into /navigate/[slug]; FloatingControls' back button knows to return to
  /start from the new screen
